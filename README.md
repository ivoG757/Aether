# Aether
Aether is a communication platform where users can create private or public realms, join communities and communicate through channels.

## Currently Implemented

- ASP.NET Core Identity authentication
- Realm membership model
- Realm roles
- Joined realms dashboard
- Realm creation with owner membership
- Layered request validation
